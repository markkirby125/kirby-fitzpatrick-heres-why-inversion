## Overview

The **kirby-fitzpatrick-heres-why-inversion** skill transforms cognitive writing science into deterministic rules for AI coding assistants, code reviews, and system documentation.

## Core Patterns

- **Heres Why Inversion**: Here's Why Inversion: state the definitive technical choice first, then unroll rationale, replacing chronological exploration logs.
- **Practical Application**: PR commit descriptions, replacing 'we tried X then Y' with 'we adopted Y because...'.
- **Verification Gate**: Enforces clean syntax, zero filler, and deterministic causality.
